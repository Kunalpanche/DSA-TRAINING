# TrailX DSA Training

I am creating this repository for the TrailX DSA Training program, where I am training 30 students in Data Structures and Algorithms using C++.

This is a 45-day training program, with 4 hours of class each day. I will document the code I write during the sessions here so students can revise the concepts, practice the examples, and track the complete learning journey day by day.

## Repository Purpose

- Document all programs I write during the training.
- Maintain day-wise C++ examples for students.
- Help students revise and practice after each class.
- Build a complete 45-day record of the TrailX DSA Training program.

## How Students Should Use This Repo

1. Open the folder for the day you want to revise.
2. Read the code and understand the logic.
3. Compile and run the program on your system.
4. Modify the code with your own inputs and variations.
5. Practice similar problems without looking at the solution first.

## Build And Run

Install a C++ compiler such as `g++` through MinGW, WSL, or another C++ development environment.

Compile and run a single file:

```powershell
g++ -std=c++17 -O2 -Wall Day1/arithmetic.cpp -o arithmetic.exe
.\arithmetic.exe
```

Another example:

```powershell
g++ -std=c++17 -O2 -Wall Day3/palindrome.cpp -o palindrome.exe
.\palindrome.exe
```
